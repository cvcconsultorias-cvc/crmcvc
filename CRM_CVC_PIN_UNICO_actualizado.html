Liquidación semanal de socios

Base de distribución de utilidad neta

Configura el porcentaje destinado al ahorro semestral y el porcentaje de comisión. La comisión solo se calcula en trabajos marcados como “Sí”. Sin trabajos con comisión, la distribución se ajusta automáticamente a 45% Fernando, 45% Angie y el porcentaje de ahorro configurado.

Reiniciar dashboard por periodo

Esta acción elimina trabajos y gastos del periodo seleccionado. La base maestra de clientes no se borra. Exporta un respaldo antes de continuar si necesitas conservar el detalle operativo.

Sincronización en tiempo real entre computadores y celulares

Para compartir los mismos datos desde cualquier ciudad, el CRM utiliza Firebase Authentication anónimo y Cloud Firestore. No necesitas crear correo ni contraseña. La configuración del proyecto se incorpora al archivo para que el acceso sea automático.

Modo local: los datos solo están en este navegador hasta conectar Firebase.

Acceso sin contraseña: cualquier persona con el enlace podrá consultar, registrar, modificar o borrar datos. No guardes información confidencial. Mantén copias de seguridad.
